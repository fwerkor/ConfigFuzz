# RQ2 GPU runtime-diversity subset (2026-08-19)

This package adds explicit runtime instrumentation to the final RQ2 GPU campaign. The tracer records rank-zero events for the executed forward path, resolved framework/attention/distributed backends, initialized process topology, and feature modules that actually execute through forward hooks. Profile-derived labels such as model family, configured precision, GQA/MQA/MHA state, and MoE enablement remain trace context and are excluded from the paper's diversity metric by the `executed-path-v1` policy.

The diversity campaign deterministically selects the lowest-SHA256 20% of frozen intents within each workload. This gives 720 framework-local intents and 4,320 method records. Exact materialized-config equivalence reduces the required measurement to 844 unique runtime configurations. Eight initial measurements hit transient `EADDRINUSE`; all eight were rerun, and the final package contains zero infrastructure-failure records.

On this instrumented subset, Raw Mutation reaches 520/720 IPDE (72.22%) and ConfigFuzz reaches 544/720 (75.56%), with 24 ConfigFuzz-only rescues and zero Raw-only regressions. For conservative executed-path diversity, both methods cover exactly 26 behavior IDs and exactly the same set of 39 behavior signatures. Signature entropy is 4.654 bits for Raw and 4.589 bits for ConfigFuzz; signature yield is 14.50 versus 14.55 per accelerator-hour. Thus the instrumentation supports the deep-execution gain, but it does not show expanded runtime-path diversity under this fixed intent pool.

`*.jsonl.gz` contains the assembled 4,320 method records. `unique-traces-*.jsonl.gz` contains one clean instrumented trace for each of the 844 unique materialized runtime configurations. `subset-plan-*.json` pins the deterministic sample; `assembly-*.json` records exact-config reuse provenance; `summary.json` contains per-framework and aggregate metrics; and `manifest.json` pins the runtime and analysis revisions and the interpretation used by the paper.
