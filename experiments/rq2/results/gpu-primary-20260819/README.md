# RQ2 GPU primary-seed results (corrected 2026-08-20)

This directory contains the final 21,600-record GPU primary-seed RQ2 package used by the paper. The frozen intent set uses seed 2026; Intent-Preserving Deep Execution (IPDE) requires preserving the requested target value and reaching `optimizer_step` or later.

The final campaign covers PyTorch Native/CUDA, DeepSpeed, Transformers/Accelerate, and Megatron-Core. Raw Mutation reaches IPDE for 2,440/3,600 intents (67.78%), while ConfigFuzz reaches 2,624/3,600 (72.89%). The paired comparison contains 2,440 both-deep cases, 976 neither-deep cases, 184 ConfigFuzz-only rescues, and zero Raw-only regressions. ConfigFuzz preserves the target value in every generated case and generates 98.72% of assigned cases, compared with 90.67% for Static-Hard.

The August 20 correction adds the workload/model-stack relations to Megatron-Core's promoted RQ2 graph and supplies the framework-default `kv_channels=None` planning context. The frozen 450 Megatron intents and requested target values are unchanged. Because the launched Megatron runner had gained `runtime-events-v1` instrumentation after the prior primary package, the older Megatron executions did not satisfy the strict unchanged-runtime-code reuse rule. All 578 unique corrected Megatron runtime configurations were therefore executed again; the corrected rerun has zero infrastructure failures. Scope-disputed RQ1 relations remain non-hard constraints.

`summary.json` contains per-framework, aggregate, and paired metrics. `manifest.json` pins compressed and uncompressed hashes and the correction provenance. The four `selective-plan-*.json.gz` files record the framework-specific configurations selected for GPU execution; `runtime-reuse-*.json` records assembly provenance. `revision-map.json` maps experiment-machine commit IDs to GitHub-published equivalent commits without rewriting the original runner revision fields.
