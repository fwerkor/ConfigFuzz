# RQ2 GPU primary-seed results (2026-08-19)

This directory contains the final 21,600-record GPU primary-seed RQ2 package used by the paper. The frozen intent set uses seed 2026; Intent-Preserving Deep Execution (IPDE) requires preserving the requested target value and reaching `optimizer_step` or later.

The final campaign covers PyTorch Native/CUDA, DeepSpeed, Transformers/Accelerate, and Megatron-Core. Raw Mutation reaches IPDE for 2,440/3,600 intents (67.78%), while ConfigFuzz reaches 2,598/3,600 (72.17%). The paired comparison contains 2,440 both-deep cases, 1,002 neither-deep cases, 158 ConfigFuzz-only rescues, and zero Raw-only regressions. ConfigFuzz preserves the target value in every generated case and generates 98.72% of assigned cases, compared with 91.72% for Static-Hard.

The current promotion is built from the final 24-target GPU RQ1 state and model-stack constraint recovery. To avoid rerunning byte-identical runtime configurations, the final assembly reuses prior execution evidence only when framework, workload, seed, launcher, launched runtime code, and the fully materialized configuration are equivalent. The four `selective-plan-*.json.gz` files record the 595 unique configurations that required new GPU execution. Eight executions initially hit transient `EADDRINUSE` failures; they were rerun after adding free-port selection, and the final package contains zero infrastructure-failure records. `runtime-reuse-*.json` records the exact provenance of every assembled framework result. `revision-map.json` maps experiment-machine commit IDs to their GitHub-published equivalent commits without rewriting the original records.

`summary.json` contains per-framework, aggregate, and paired metrics. `manifest.json` pins compressed and uncompressed hashes and the promotion revision. The current `behavior_signature` field is not used for the paper's runtime-diversity claim because this executor version derives it from milestone, outcome, and final error text rather than branch/backend/topology instrumentation.
